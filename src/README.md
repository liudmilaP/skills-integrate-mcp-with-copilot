# Mergington High School Activities API

A super simple FastAPI application that allows students to view and sign up for extracurricular activities.

## Features

- View all available extracurricular activities
- Teacher sign-in to register and unregister students
- Public activity and participant list

## Getting Started

1. Install the dependencies:

   ```
   pip install fastapi uvicorn
   ```

2. Generate a password hash for the teacher account:

   ```
   python scripts/hash_password.py
   ```

3. Configure the teacher account and session signing key in the server environment.
   Do not commit credentials or secrets:

   ```
   export TEACHER_USERNAME=teacher
   export TEACHER_PASSWORD_HASH='pbkdf2_sha256$...'
   export SESSION_SECRET="$(python -c 'import secrets; print(secrets.token_urlsafe(48))')"
   ```

   Set `COOKIE_SECURE=true` when serving the application over HTTPS. Leave it
   unset for local HTTP development.

4. Run the application from the repository root:

   ```
   uvicorn app:app --app-dir src --reload
   ```

5. Open your browser and go to:
   - API documentation: http://localhost:8000/docs
   - Alternative documentation: http://localhost:8000/redoc

## API Endpoints

| Method | Endpoint                                                          | Description                                                               |
| ------ | ----------------------------------------------------------------- | ------------------------------------------------------------------------- |
| GET    | `/activities`                                                     | Public list of activities and participants                                |
| POST   | `/auth/login`                                                     | Sign in as a teacher and receive an HTTP-only session cookie               |
| GET    | `/auth/me`                                                        | Check the current teacher session                                         |
| POST   | `/auth/logout`                                                    | Sign out and clear the session cookie                                     |
| POST   | `/activities/{activity_name}/signup?email=student@mergington.edu` | Register a student (teacher session required)                             |
| DELETE | `/activities/{activity_name}/unregister?email=student@mergington.edu` | Unregister a student (teacher session required)                        |

Teacher credentials are configured with `TEACHER_USERNAME` and a
`TEACHER_PASSWORD_HASH` generated by `scripts/hash_password.py`. The
`SESSION_SECRET` must be at least 32 characters and should be unique and
confidential. Authentication configuration is intentionally not stored in a
checked-in JSON file.

## Data Model

The application uses a simple data model with meaningful identifiers:

1. **Activities** - Uses activity name as identifier:

   - Description
   - Schedule
   - Maximum number of participants allowed
   - List of student emails who are signed up

2. **Students** - Uses email as identifier:
   - Name
   - Grade level

All data is stored in memory, which means data will be reset when the server restarts.
